# EscrowDesk — 概述

## 一句话

代客部署/铸币这单生意，把微信口头单变成 BSC 上的托管验收：客户锁服务费，开发者交合约与材料，条件满足或确认后放款。

## 赛道

BNB Hack · DeSoc（验收说明可走 AI）

## 问题与目标

- 痛点：微信成交下，钱和活对不上，双方缺乏可执行的交付与验收约定。
- 目标用户：找人代部署/铸币的客户，以及接单的开发者。
- 为什么选 BNB Chain：BSC 上代客部署/铸币需求多，适合把托管与验收上链。

## 流程

1. 客户锁服务费 + 写明验收条件  
2. 开发者交付：合约地址、验证链接、说明书哈希  
3. 条件满足或客户确认 → 放款  

## 硬规则（比赛版）

- 开发者未在期限内交付 → 自动退款给客户  
- 已交付后 72 小时客户不操作 → 视为验收并放款  
- 客户在窗口内拒绝 → 双方各押一笔进入争议，由指定仲裁地址裁定
