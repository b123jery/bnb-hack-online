# BNB Hack Online — Project Starter

BNB Chain [BNB Hack: Online Edition](https://www.bnbchain.org/en/hackathons/bnb-ai-hack) 参赛项目脚手架。

## 赛道参考

- AI
- DeSoc
- DeSci
- DePIN

## 快速开始

```bash
# 安装依赖（按你实际技术栈调整）
npm install

# 本地开发
npm run dev
```

```
.
```
